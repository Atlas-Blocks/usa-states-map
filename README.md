# USA States Map

Interactive Gutenberg USA states map block for WordPress.

---

## Overview

USA States Map is a custom Gutenberg block that allows editors to display an interactive SVG map of the United States directly inside the WordPress block editor.

The block includes customizable state selection, editor-side controls, configurable colors, optional state lists, and responsive frontend rendering.

Built using:

* WordPress Block Editor APIs
* React
* SVG rendering
* SCSS
* @wordpress/scripts

## Features

* Interactive SVG USA map
* Select and highlight individual states
* Custom active and default state colors
* Optional selected states list
* Responsive frontend rendering
* Editor-side search and selection controls
* Clean Gutenberg editor integration
* Frontend and editor styling parity
* Configurable block settings
* Built with modern WordPress block architecture

---

## Block Controls

### State Selection

Editors can:

* search for states
* add/remove states
* visually highlight selected regions

### Color Controls

Customize:

* active state color
* inactive/default state color

### Display Options

Toggle:

* selected states list visibility
* layout variations
* list title display

---

## Installation

### Manual Installation

1. Download or clone this repository.
2. Place the plugin folder inside:

```txt
wp-content/plugins/
```

3. Activate the plugin from the WordPress admin panel.
4. Add the block through the Gutenberg editor.

## Development Setup

### Install Dependencies

```bash

```

### Start Development Build

```bash

```

### Production Build

